# StudySphere

StudySphere is a simple and student-friendly learning website designed for engineering and college students.

It brings useful academic and career-related resources together in one place, making it easier for students to learn, practice and prepare for their future.

## Project Overview

StudySphere provides a clean and organized learning space where students can explore:

- Study Notes
- Programming Practice
- Question Papers
- Placement Preparation

The website focuses on simplicity, easy navigation and a student-friendly design.

## Features

- Clean and modern user interface
- Responsive design for different screen sizes
- Simple navigation bar
- Smooth scrolling between sections
- Study resources section
- Programming practice section
- Question papers section
- Placement preparation section
- Student-focused features section
- Learning journey section
- About section
- Contact section
- Responsive layout for mobile devices

## Technologies Used

- HTML5
- CSS3
